BLOC 1Compétence 1.1 : Recenser et identifier les ressources numériques

Descriptif de la preuve : Modélisation conceptuelle, logique et relationnelle des données collectées pour la JPO, validées formellement en 3ème Forme Normale (3NF).

Dictionnaire de 14 données, GDF & Modèle Logique de Données (MLD) :
• FORMATION (codeForm, nomForm, typeForm, salleForm)
• VISITEUR (numVisi, nomVisi, prenomVisi, statutVisi, emailVisi)
• VISITE (#numVisi, #codeForm, heureArrivee)

La normalisation stricte a permis d'écarter toute dépendance transitive pour écarter le risque de redondances.

BLOC 2Compétence 2.3 : Résoudre des incidents liés aux applications

Descriptif de la preuve : Résolution méthodique d'une violation de contrainte d'intégrité référentielle (Erreur MySQL #1452) lors des tests unitaires Back-end.

Rapport d'incident textuel :

• Cause : Les jeux de tests unitaires visaient par défaut les codes formations 1 et 2, or la table parente FORMATION avait été initialisée avec des identifiants démarrant à l'ID 3 pour correspondre aux numéros réels des salles de l'école.

• Résolution : Mise à jour corrective du script SQL pour insérer de manière exhaustive les salles de 1 à 221 en amont.

BLOC 3Compétence 3.3 : Participer à l’évolution d’un site Web exploitant les données de l’organisation

Descriptif de la preuve : Écriture complète du script relationnel SQL générant la persistance des formulaires.

jpo.sql (Création des tables et déclaration externe des FK) 
CREATE TABLE FORMATION (
    codeForm INT AUTO_INCREMENT PRIMARY KEY,
    nomForm VARCHAR(50) NOT NULL
) ENGINE=InnoDB;

CREATE TABLE VISITE (
    numVisi INT,
    codeForm INT,
    PRIMARY KEY (numVisi, codeForm)
) ENGINE=InnoDB;

-- Contraintes d'intégrité isolées proprement hors-table
ALTER TABLE VISITE 
ADD CONSTRAINT FK_VISITE_FORMATION 
FOREIGN KEY (codeForm) REFERENCES FORMATION(codeForm);
BLOC 4Compétence 4.1 & 4.2 : Mode Projet (Objectifs et Planification)

Descriptif de la preuve : Développement des requêtes SQL décisionnelles avancées pour extraire en temps réel les indicateurs d'affluence.

Requete_Statistiques.sql (Jointures et regroupement d'agrégats) 
SELECT F.nomForm, COUNT(V.numVisi) AS nombre_visiteurs
FROM FORMATION F
INNER JOIN VISITE V ON F.codeForm = V.codeForm
INNER JOIN VISITEUR VT ON V.numVisi = VT.numVisi
WHERE VT.statutVisi = 'STI2D'
GROUP BY F.nomForm
ORDER BY nombre_visiteurs DESC;
