BLOC 1Compétence 1.1 : Recenser et identifier les ressources numériques

Descriptif de la preuve : Modélisation de données et conception normalisée de la base de données relationnelle MySQL, validée rigoureusement en 3ème Forme Normale (3NF).

Modèle Logique de Données (MLD 3NF) :
• FORMATION (codeForm, nomForm, typeForm, salleForm)
• VISITEUR (numVisi, nomVisi, prenomVisi, statutVisi, emailVisi, telVisi)
• VISITE (#numVisi, #codeForm, heureArrivee)

Le Graphe de Dépendances Fonctionnelles (GDF) a validé l'absence de redondances transitives, garantissant une structure optimale éliminant les anomalies d'insertion.

BLOC 2Compétence 2.3 : Résoudre des incidents liés aux applications

Descriptif de la preuve : Résolution méthodique d'un blocage d'insertion (Erreur MySQL #1452) survenu lors des tests de transactions unitaires.

Rapport d'incident technique :

  • Symptôme : Error 1452: Cannot add or update a child row: a foreign key constraint fails.
  • Analyse : La table parente FORMATION avait été initialisée avec des codes correspondant aux numéros réels des salles (commençant à l'ID 3), tandis que les scripts d'essais simulaient des transactions sur les codes par défaut 1 et 2, inexistants dans la table parente.
  • Résolution : Mise à jour du script SQL pour insérer l'ensemble des salles (1 à 221) en amont des tests afin de réaligner l'intégrité relationnelle.
BLOC 3Compétence 3.3 : Participer à l’évolution d’un site Web exploitant les données de l’organisation

Descriptif de la preuve : Écriture complète du script de structure relationnelle de production SQL, isolant rigoureusement les contraintes métiers.

jpo.sql (Création des structures et contraintes relationnelles) 
CREATE TABLE FORMATION (
    codeForm INT AUTO_INCREMENT PRIMARY KEY,
    nomForm VARCHAR(50) NOT NULL,
    salleForm INT NOT NULL
) ENGINE=InnoDB;

CREATE TABLE VISITE (
    numVisi INT,
    codeForm INT,
    heureArrivee TIME NOT NULL,
    PRIMARY KEY (numVisi, codeForm)
) ENGINE=InnoDB;

-- Déclaration externe et propre des contraintes de clés étrangères
ALTER TABLE VISITE 
ADD CONSTRAINT FK_VISITE_FORMATION 
FOREIGN KEY (codeForm) REFERENCES FORMATION(codeForm);
BLOC 4Compétence 4.1 & 4.2 : Mode Projet (Objectifs et Planification)

Descriptif de la preuve : Conception des scripts SQL décisionnels avancés requis par la direction pour analyser l'affluence de la JPO en temps réel.

Requete_Statistiques.sql (Jointures, tris et agrégations) 
SELECT F.nomForm, COUNT(V.numVisi) AS nombre_visiteurs
FROM FORMATION F
INNER JOIN VISITE V ON F.codeForm = V.codeForm
INNER JOIN VISITEUR VT ON V.numVisi = VT.numVisi
WHERE VT.statutVisi = 'STI2D'
GROUP BY F.nomForm
ORDER BY nombre_visiteurs DESC;
