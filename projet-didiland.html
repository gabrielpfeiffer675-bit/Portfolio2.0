BLOC 1Compétence 1.3 : Mettre en place et vérifier les niveaux d’habilitation associés à un service

Descriptif de la preuve : Isolation stricte des traitements applicatifs Back-end selon le profil stocké en Session (Admin vs Technicien).

Document.php (Contrôleur CodeIgniter 3 — Guard de rôle) 
public function ajouter() {
    $user_role = $this->session->userdata('role');
    if (!$this->session->userdata('logged_in') || $user_role !== 'Admin') {
        show_error("Accès refusé : Vous ne disposez pas des habilitations requises.", 403);
        return;
    }
    $this->load->view('documents/ajouter');
}

BLOC 5Compétence 5.1 : Réaliser les tests d’intégration et d’acceptation d’un service

Descriptif de la preuve : Phase de recette logicielle. Script de contrôle de cohérence bloquant la suppression d'une attraction si des notices lui sont encore rattachées (Contrôle d'intégrité métier).

Vérification d'intégrité référentielle applicative (PHP / SQL) 
public function verifier_et_supprimer($id_attraction) {
    $this->db->where('id_attraction', $id_attraction);
    if ($this->db->count_all_results('DOCUMENT') > 0) {
        return false; // Interdiction : notices orphelines évitées
    }
    $this->db->where('id', $id_attraction);
    return $this->db->delete('ATTRACTION');
}
