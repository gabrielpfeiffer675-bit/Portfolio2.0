Application "didiland.docs"

Stage de 1ère Année PHP & CodeIgniter 3 MySQL

1. Fiche d'identité

Développé en autonomie durant mon stage auprès de M. Roser (Responsable administration) au parc d'attractions Didiland. L'environnement a été déployé localement sur Laragon avec configuration d'un Hôte Virtuel (didiland.docs).

2. Problématique & Besoins

Le parc gérait ses notices d'attractions, manuels de maintenance et consignes de sécurité obligatoires de manière fragmentée. Le besoin était de centraliser ces ressources critiques au sein d'une plateforme unique avec recherche multicritères et restriction des accès selon les rôles (Admin / Technicien).

3. Réalisations techniques (Preuves)

  • Base de données : Modélisation normalisée reliant les tables DOCUMENT, ATTRACTION, TYPE_DOCUMENT et UTILISATEUR.
  • Module CRUD : Gestion dynamique complète des documents avec rendu asynchrone propulsé par l'extension JavaScript DataTables.
  • Intégrité applicative : Utilisation d'un trigger logique empêchant la suppression d'une attraction si des notices restent orphelines.
Contrôle d'intégrité référentielle avant suppression (PHP) 
public function delete_attraction($id) {
    // 1. Contrôle par requête COUNT du nombre de notices liées
    $this->db->where('id_attraction', $id);
    $count = $this->db->count_all_results('DOCUMENT');

    if ($count > 0) {
        // Transaction annulée pour éviter les données orphelines
        return FALSE; 
    } else {
        $this->db->where('id', $id);
        return $this->db->delete('ATTRACTION');
    }
}

4. Sécurité & Cybersécurité

Authentification robuste implémentée via la fonction native PHP password_verify() avec chiffrement en BCRYPT. Une veille technologique a été rédigée concernant la dépréciation des algorithmes MD5/SHA-1, planifiant une future mise à niveau vers Argon2id (standard de référence de l'ANSSI).

5. Gestion des incidents (Le bug résolu)

Incident : Corruption des caractères spéciaux et accentués (ex : 'Ã©' à la place de 'é') lors de l'extraction des documents sous forme d'archive ZIP générée sous environnement Windows.

Résolution : Implémentation autonome d'un traitement de remappage transparent à l'aide de la fonction native PHP strtr() pour assurer une parfaite portabilité multi-systèmes.
